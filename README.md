# Hi, I'm Bryan 👋

I build open-source tools for data visualization and scientific computing. I'm a co-creator and core team member of [Bokeh](https://github.com/bokeh/bokeh), the original author of [conda](https://github.com/conda/conda), and a former contributor to [RAPIDS](https://github.com/rapidsai).

## Open-source highlights

- 📊 [**Bokeh**](https://github.com/bokeh/bokeh) - interactive data visualization for modern web browsers
- 📦 [**conda**](https://github.com/conda/conda) - cross-platform package and environment management
- ⚡ [**RAPIDS**](https://github.com/rapidsai) - GPU-accelerated data science and analytics
